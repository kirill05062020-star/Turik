# Известные ограничения Turik (честный список)

1. **Сборка не выполнялась на устройстве разработки.** Проект собран вручную
   по официальным координатам (Minecraft 1.21.11, Fabric API 0.141.6+1.21.11,
   yarn 1.21.11+build.6, Loom 1.17.21 (выбрана для сборки на JDK 21) — проверены
   через meta.fabricmc.net и Modrinth API). Ошибки компиляции возможны.
2. **Имена методов yarn** в паре мест могли измениться в 1.21.9–1.21.11
   (`player.fishHook`, `getHungerManager`, `useKey`, `Framebuffer.getColorAttachment`,
   `prevX/prevZ`, `updateBlockBreakingProgress`, `renderFireOverlay`). Все такие
   точки локализованы в mixin-слое и 2–3 модулях и чинятся быстро.
3. **Fog** — экранная атмосферная дымка (градиент через собственный шейдер),
   а не глубинный туман ванили: правка конвейера тумана 1.21.11 нестабильна.
4. **XRay** выделяет блоки (обводка/заливка через собственный world-шейдер)
   и не делает остальной мир прозрачным — прозрачность потребует отдельного
   render-layer mixin.
5. **Atmosphere-пресеты** дают перекраску неба, осадки и GPU-частицы; купол
   Saturn упрощён до кольца частиц.
6. **Blur** работает только когда основной framebuffer доступен для сэмплирования;
   при недоступности панели деградируют в тёмные скруглённые плашки.
7. **Шрифт**: в комплекте один TTF (Manrope variable, дефолтное начертание
   Regular); Medium/SemiBold/Bold синтезируются мультипроходной штамповкой
   при растеризации — качество близко к настоящим начертаниям, но не идентично.
8. **Anti-cheat**: модули движения/боя клиентские; на защищённых серверах
   возможны блокировки — клиент ничего не скрывает принудительно.
9. **TriggerBot Smart** использует упрощённую модель крита (без учёта enchant).
10. **ItemScroller** двигает предметы пачками через quick-move; «hover-режим»
    оставлен как флаг без отдельной механики наведения.
